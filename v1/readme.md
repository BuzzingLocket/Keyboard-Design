*A custom keyboard by BuzzingLocket*

* Keyboard Maintainer: [Evan](https://github.com/BuzzingLocket)
* Hardware Supported: Raspberry Pi Pico RP2040
* Hardware Availability: Custom build

Make example for this keyboard (after setting up your build environment):

    make v1:default

Flashing example for this keyboard:

    make v1:default:flash
